# K230 + STM32F103 + X42S Emm滚球联动

此工程独立于已经验证成功的`电机`工程。

## 接线

- K230 IO11 TX -> STM32 PA10 USART1_RX
- K230 IO12 RX <- STM32 PA9 USART1_TX（当前程序可不接）
- STM32 PA2 USART2_TX -> X42S TTL RX
- STM32 PA3 USART2_RX <- X42S TTL TX（当前程序可不接）
- 三者GND必须共地
- X42S独立12V供电

## 固定配置

- X42S固件：Emm
- 地址：1
- 波特率：115200
- 校验：固定0x6B
- MotType：1.8度
- MStep：256
- 水平位置已经保存为X42S单圈硬件零点

## 控制原理

K230每20ms发送：

```text
AA 55 valid xL xH yL yH sum8
```

STM32计算滤波位置和球速：

```text
电机目标角度 = Kp * 球位置 + Kd * 球速度
```

`Kp`把球拉回中心，`Kd`根据球速提前反向摆动，使球减速。电机使用相对坐标零点的绝对位置命令，避免相对命令不断累计漂移。

初始参数位于`User/main.c`：

- `CONTROL_KP = 0.0120`
- `CONTROL_KD = 0.0045`
- 最大角度`+/-7度`
- 电机速度60RPM、加速度档位240
- 每20ms最大变化`1.2度`

丢球处理：

- 最后在左边（正坐标）丢球：电机转到`+4度`，让球向右返回。
- 最后在右边（负坐标）丢球：电机转到`-4度`，让球向左返回。
- 找回最多持续1.2秒，仍未识别则回硬件零点。
- 如果是K230串口整体中断超过150ms，不盲目找球，直接回零。
